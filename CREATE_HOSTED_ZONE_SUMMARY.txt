## 🔄 User Flows

### Happy Path (Success)
```
1. Visit /hosted-zones/create
2. Fill zone name "example.new.com"
3. Select type "Private"
4. Add optional description
5. Click "Create Zone"
6. Spinner shows (2 seconds)
7. Success message + checkmark
8. Auto-redirect to /hosted-zones
9. Toast: "Zone Created - example.new.com..."
```

### Validation Error
```
1. Try to submit empty form
2. Error: "Zone name is required"
3. Type "ab"
4. Error: "must be at least 3 characters"
5. Type "invalid"
6. Error: "valid domain name (e.g., example.com)"
7. Fix all errors
8. Submit successfully
```

### Creation Error (10% demo chance)
```
1. Fill form correctly
2. Click "Create Zone"
3. Spinner shows
4. Error state appears
5. Click "Try Again"
6. Back to form (data preserved)
7. Retry submission
```

### Cancel
```
1. Fill some data
2. Click "Cancel"
3. Navigate back to /hosted-zones
4. Data not saved
```
